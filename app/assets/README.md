Os ícones da interface são fornecidos por @expo/vector-icons (Ionicons), com expo-font instalado diretamente para os builds nativos.

`icon.png` e `adaptive-icon.png` são os ícones locais do aplicativo Android, em 1024×1024, com a ampulheta vermelha do Deadline. São reproduzidos pelo script `scripts/gerar-icones.ps1`, usando desenho vetorial convertido em PNG pelo System.Drawing do Windows. Não dependem de imagens externas.
